# MAX Messenger

Простое веб-приложение для отправки и получения текстовых сообщений в мессенджере MAX через сервис GREEN-API.

Проект разработан на React, TypeScript и Vite в рамках тестового задания на должность Frontend Developer.

## Запуск проекта

Перед запуском необходимо убедиться, что на компьютере установлены Node.js и npm.

Проверить установленные версии можно командами:

node -v
npm -v

Рекомендуемые версии:

- Node.js 22.x
- npm 10.x

После проверки версий установите зависимости проекта:

npm ci

После завершения установки запустите приложение:

npm run dev

После запуска Vite выведет адрес локального сервера в консоли. Откройте этот адрес в браузере.

## Использование

После запуска приложения необходимо подключить инстанс GREEN-API.

1. Введите `idInstance` — идентификатор вашего инстанса GREEN-API.
2. Введите `apiTokenInstance` — токен доступа к инстансу.
3. Введите номер телефона получателя в международном формате.
4. Нажмите кнопку **«Создать чат»**.
5. После успешного создания чата можно отправлять текстовые сообщения.
6. Входящие сообщения автоматически появляются в открытом диалоге.

Для отправки сообщения нажмите **Enter** или кнопку **«Отправить»**.

Для переноса строки используйте **Shift + Enter**.

Приятного использования! 🚀
